# Spaceship Titanic: Ensemble Models

## Overview

Binary classification project based on the Spaceship Titanic dataset.
The project explores decision trees and ensemble methods for predicting
whether a passenger was transported to another dimension.

## Workflow

- Exploratory Data Analysis
- Missing-value handling
- Categorical feature encoding
- Log transformation of skewed spending features
- Cabin feature extraction
- Decision Tree
- Random Forest
- CatBoost
- Hyperparameter analysis
- Feature importance

## Models

- Decision Tree
- Random Forest
- CatBoost

## Results

Best model: CatBoost

- Test Accuracy: 0.801
- Test F1-score: 0.801

## Tech Stack

Python, pandas, NumPy, scikit-learn, CatBoost,
Matplotlib, Seaborn
